1. 분석 개요

Statistics 분석은 크롤링된 원본 CSV(기사·댓글·대댓글)를 업로드하면 플랫폼(네이버 뉴스 / 네이버 카페 / 유튜브)과 분석 종류(article / statistics / reply / rereply)의 조합에 맞는 전용 통계 파이프라인을 서버에서 실행하여, 그래프(PNG)와 표(CSV)를 함께 생성합니다.

결과는 웹 뷰어에서 표를 즉석에서 인터랙티브 차트로 다시 그려 보여주며, 원본 그래프 이미지와 표는 그대로 zip으로 다운로드할 수도 있습니다.

입력 데이터 조건: 이 분석은 토큰화되지 않은 원본 CSV를 대상으로 합니다 (KEM KIM/네트워크 분석과 반대로, 형태소 분석 전 원본을 사용합니다). 날짜 열은 이름에 Date가 포함되어야 자동으로 인식됩니다.

2. 사용법

  1. 웹 뷰어 좌측 레일의 ＋ 새 프로젝트를 눌러 원본 CSV를 업로드하거나, 크롤링 DB에서 선택으로 완료된 크롤링 결과를 바로 불러옵니다.
  2. 플랫폼(네이버 뉴스 / 네이버 카페 / 유튜브)과 분석 종류를 선택합니다 — 선택 가능한 조합은 3장을 참고하세요.
  3. 분석 시작을 누르면 서버에서 파이프라인이 실행되고, 완료되면 결과가 자동으로 내 프로젝트로 저장됩니다.
  4. 프로젝트를 열면 생성된 모든 표를 뷰어에서 차트로 확인하거나, zip으로 원본 그래프·CSV를 내려받을 수 있습니다.

3. 플랫폼 × 분석 종류

플랫폼마다 지원하는 분석 종류가 다릅니다. 지원하지 않는 조합은 업로드 화면에서 아예 선택할 수 없습니다.

article 분석 기사/게시글 단위

월별·일별 게시량 추이, 요일별 발행 패턴, 게시글 유형 분포, 상위 발행처(언론사/채널) 순위, 발행처별 참여도(게시글당 반응 수) 등을 계산합니다.

statistics 분석 네이버 뉴스 전용

기사 지표에 대한 기술통계(평균·표준편차 등)와 시계열 통계를 중심으로 좀 더 정량적인 표를 만듭니다.

reply 분석 댓글 단위

날짜별 댓글 수 추이, 댓글 감성(긍정/부정/중립) 분포, 주요 지표 간 상관관계 히트맵, 작성자별 댓글 수 상위 10명, 좋아요·싫어요와 감성을 함께 본 참여도 비교, 반응이 양극단으로 몰린 "논란의 댓글" 상위 20개, 좋아요 vs 싫어요 산점도 등을 생성합니다.

rereply 분석 대댓글 단위

reply 분석과 유사한 지표를 대댓글 단위로 계산하여, 원댓글 대비 논쟁이 얼마나 확산됐는지를 함께 볼 수 있습니다.

4. 혐오도 분석

플랫폼과 무관하게 선택할 수 있는 별도 분석 종류입니다. 데이터에 Hate/Clean 또는 여성·가족 등 10개 세부 레이블 열이 포함되어 있으면 자동으로 형식을 판별하여:

  • 기본 통계 · 월별/일별/7일 이동평균 추이
  • 혐오 표현이 가장 많이 몰린 상위 기간(Top-N) 분석
  • 지표 간 상관관계 히트맵
  • 분포·추세 그래프

를 <원본>_hate_analysis/ 폴더에 생성합니다.

5. 공통 파생 표

어떤 분석 종류를 고르든, 원본 표들과는 별도로 다음 표가 항상 추가로 생성됩니다:

  • 요일×시간대 히트맵: 날짜 열이 있으면 요일(월~일)과 시간(0~23시)별 게시량을 표로 만들어, 언제 활동이 가장 활발한지 한눈에 보여줍니다.
  • 7기간 이동평균 / 누적: 날짜 축을 가진 표마다 대응하는 _trend(7기간 이동평균)와 _cumulative(누적) 표를 별도 카드로 추가해, 단기 변동과 장기 추세·누적 성장을 따로 확인할 수 있게 합니다.
  • 기술통계(SPSS 스타일): 수치형 열들에 대해 평균·표준편차·왜도·첨도 등 기술통계와 정규성 검정 표를 자동으로 추가합니다.

이 파생 표들은 대응하는 그래프 이미지가 원래는 없었지만, 화면에 이미 잘 그려지는 다른 표들과 같은 규칙으로 그래프를 자동 생성해 zip 다운로드와 웹 화면의 표 목록이 항상 일치하도록 합니다.

6. 결과 파일 설명

  • csv_files/*.csv: 분석 종류별로 생성된 모든 표 (뷰어가 이 표들을 읽어 차트로 그립니다)
  • graphs/*.png: 각 표에 대응하는 그래프 이미지 (zip 다운로드용)
  • metadata.json: 분석에 사용한 플랫폼/분석 종류, 원본 파일명, 행 수, 분석 시각
  • description.txt: 각 그래프가 무엇을 보여주는지에 대한 설명

7. 활용 팁 & 주의사항

플랫폼/분석 종류 조합 오류: 지원하지 않는 조합(예: 네이버 카페 + rereply 분석)을 선택하면 분석이 시작되지 않습니다 — 3장의 표를 먼저 확인하세요.

  • 날짜 열 이름에 Date가 포함되어야 요일×시간대 히트맵과 이동평균/누적 표가 생성됩니다.
  • 행 수가 너무 적은 표(대략 8행 미만이거나 400행을 초과)는 이동평균/누적 표 생성에서 제외됩니다 — 추세를 보기에 유의미한 크기가 아니기 때문입니다.
  • 결과는 KEM KIM/네트워크 분석과 마찬가지로 로그인 상태에서 분석하면 내 프로젝트로 자동 저장됩니다.
