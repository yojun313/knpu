1. 분석 개요

크롤링한 원본 CSV를 올리면, 통계 표와 그래프를 자동으로 만들어 주는 도구입니다. 통계 지식이 없어도 결과를 바로 읽을 수 있도록 모든 표에 한글 항목명을 붙여 둡니다.

원본 CSV 업로드→ 플랫폼 · 분석 종류 선택→ 서버에서 분석 실행→ 표 + 그래프 생성→ 내 프로젝트에 저장

분석 한 번을 돌리면 세 묶음의 결과가 함께 나옵니다.

묶음내용언제 생기나
① 기본 분석 고른 분석 종류(기사·댓글 등)에 맞는 추이·분포·순위 표와 그래프 항상
② 통계 분석 11종 기술통계·상관·회귀·군집 등 SPSS에서 하던 분석 (7장) 항상 (조건 충족 시)
③ 공통 파생 표 요일×시간대 히트맵, 이동평균·누적 추이 (8장) 날짜 열이 있을 때

입력은 "토큰화하지 않은 원본 CSV"입니다. KEM KIM·네트워크 분석은 형태소 분석을 거친 토큰 파일을 쓰지만, Statistics는 그 반대로 크롤링 직후의 원본을 그대로 사용합니다. 날짜 열은 이름에 Date가 들어 있어야 자동으로 인식됩니다.

2. 사용법

  1. 데이터 준비 — 좌측 사이드바의 ＋ 새 프로젝트에서 원본 CSV를 올리거나, 크롤링 DB에서 선택으로 완료된 크롤링 결과를 바로 가져옵니다. 크롤링 DB에서 고르면 파일을 내려받을 필요 없이 서버가 직접 읽습니다.
  2. 분석 종류 선택 — 플랫폼(네이버 뉴스 / 네이버 카페 / 유튜브)과 분석 종류를 고릅니다. 지원하지 않는 조합은 선택 자체가 안 되니 3장 표를 참고하세요.
  3. 실행 또는 예약 — 바로 실행하거나 시각을 지정해 예약할 수 있습니다. 분석은 서버에서 돌기 때문에 창을 닫거나 다른 기기로 옮겨도 계속 진행됩니다.
  4. 진행 확인 — 사이드바 작업 목록에서 진행 중인 작업을 누르면 실시간 로그가 열립니다. 지금 어떤 분석을 하고 있는지 단계별로 보입니다 (10장).
  5. 결과 확인 — 끝나면 자동으로 내 프로젝트에 저장됩니다. 프로젝트를 열면 모든 표를 화면에서 차트로 볼 수 있고, 원본 그래프·CSV는 zip으로 내려받을 수 있습니다.

5. 혐오도 분석

댓글에 혐오 표현이 얼마나 담겼는지를 수치로 바꿔 시간에 따른 변화를 봅니다.

5-1. 입력 형식 3가지 (자동 판별)

형식들어 있는 열설명

6-1. 설정

설정선택지설명
기간 단위 total · 1d · 1w · 1m · 3m · 6m · 1y 전체를 하나로 묶을지, 일·주·월·분기·반기·연 단위로 나눠 각각 만들지 정합니다
단어 수10 ~ 500 (기본 100) 그림에 넣을 상위 단어 개수
제외 단어직접 입력 의미 없이 자주 나오는 단어(예: 기자, 뉴스)를 빼고 싶을 때

6-2. 생성 결과

  • graphs/wordcloud_<기간>.png — 기간마다 워드클라우드 이미지 1장
  • csv_files/wordcount_<기간>.csv — 그 기간의 단어별 빈도표 (그림만으로는 정확한 수치를 못 읽으므로 함께 제공)

반드시 토큰화된 CSV를 사용하세요. Text 열이 경찰,수사,발표처럼 쉼표로 나뉘어 있어야 합니다. 기간 단위를 1d로 두고 몇 년치를 넣으면 이미지가 수백 장 생성되니 기간이 길면 1m 이상을 권합니다.

7. 통계 분석 11종 (SPSS 스타일)

어떤 분석 종류를 고르든 자동으로 함께 실행되는 정통 통계 분석입니다. SPSS에서 메뉴를 눌러 가며 하던 작업을 한 번에 끝냅니다. 결과 표의 항목명은 모두 한글이며, 파일명은 spss_로 시작합니다.

분석 대상 열은 자동으로 고릅니다 — ID·URL·본문처럼 통계에 의미 없는 열은 제외하고, 수치형은 최대 10개, 범주형(값 종류가 2~20개인 열)은 최대 6개까지 사용합니다.

① 기술통계 spss_descriptives

각 수치 항목의 평균·표준편차·중앙값·사분위수·최솟값·최댓값과 분포 모양을 나타내는 왜도·첨도, 그리고 95% 신뢰구간을 계산합니다.

왜도(Skewness)
분포가 한쪽으로 치우친 정도. 0에 가까우면 좌우대칭, 양수면 오른쪽으로 꼬리가 깁니다 (대부분 값이 작고 일부만 아주 큰 경우 — 좋아요 수가 대표적입니다).
첨도(Kurtosis)
분포가 뾰족한 정도. 값이 크면 평균 근처에 몰려 있고 극단값이 드물게 튑니다.
95% 신뢰구간
"참 평균이 이 범위 안에 있을 것"이라 말할 수 있는 구간입니다.

② 정규성 검정 spss_normality

데이터가 정규분포(종 모양)를 따르는지 검정합니다. 이후 어떤 통계 기법을 써야 할지 판단하는 근거가 됩니다.

  • 표본이 5,000개 이하 → Shapiro-Wilk 검정
  • 5,000개 초과 → 5,000개를 무작위로 뽑아 Kolmogorov-Smirnov 검정

p-value가 0.05 이상이면 "정규분포를 따름", 미만이면 "따르지 않음"으로 표에 적힙니다. 댓글 좋아요 수처럼 한쪽으로 몰린 데이터는 대부분 정규분포를 따르지 않습니다 — 정상입니다.

③ 빈도분석 spss_frequencies_<열이름>

범주형 항목마다 각 값이 몇 번 나왔는지, 전체의 몇 %인지를 누적 비율과 함께 정리합니다. 범주형 열 하나당 표 하나가 생깁니다.

④⑤ 상관분석 spss_correlation_pearson / _spearman

두 항목이 함께 커지고 함께 작아지는 관계인지 숫자로 나타냅니다. 상관계수 표와 유의확률(p-value) 표가 각각 생성됩니다.

Pearson 상관
직선 관계의 강도를 봅니다. 정규분포를 따르는 데이터에 적합합니다.
Spearman 상관
순위를 기준으로 계산해, 정규분포가 아니거나 극단값이 있어도 안정적입니다. 댓글 데이터에는 보통 이쪽이 더 믿을 만합니다.

계수는 -1 ~ 1. 0.7 이상이면 강한 양의 관계, -0.7 이하면 강한 음의 관계로 봅니다. 상관이 있다고 인과관계가 있는 것은 아닙니다.

⑥ 회귀분석 spss_regression_summary / _coefficients / _vif

한 항목을 나머지 항목들로 설명·예측할 수 있는지 봅니다. (예: 좋아요 수를 댓글 길이·싫어요 수 등으로 설명할 수 있을까?)

R² (결정계수)
모델이 전체 변동의 몇 %를 설명하는지. 0.3이면 30% 설명.
회귀계수
해당 항목이 1 늘 때 결과가 얼마나 변하는지. p-value가 0.05 미만이면 의미 있는 영향으로 봅니다.
VIF (다중공선성)
설명 변수끼리 너무 비슷한지 점검하는 지표입니다. 10을 넘으면 그 변수들이 사실상 같은 정보를 담고 있어 해석이 왜곡될 수 있습니다.

⑦ 군집분석 (K-means) spss_cluster_summary / _profile

비슷한 성격의 데이터끼리 자동으로 묶어 집단을 찾아냅니다. (예: 조용한 다수 / 열성 반응 집단 / 논쟁 유발 집단)

  • 군집 수 k를 2~6까지 바꿔 가며 시도하고, 실루엣 계수가 가장 높은 k를 자동 선택합니다.
  • _profile 표에는 군집별 평균값과 크기(N)가 나와, 각 집단의 성격을 읽을 수 있습니다.
실루엣 계수
군집이 얼마나 잘 나뉘었는지를 -1 ~ 1로 나타냅니다. 0.5 이상이면 뚜렷하게 나뉜 편, 0.2 아래면 경계가 흐릿하다는 뜻입니다.

데이터가 5만 행을 넘으면 5만 행을 무작위로 뽑아 분석합니다 (9장 참고). 표의 비고 칸에 표본 사용 여부가 적힙니다.

⑧ 요인분석 / PCA spss_pca_variance / _loadings

여러 항목에 공통으로 숨어 있는 축을 찾아 변수를 압축합니다. (예: 좋아요·싫어요·대댓글 수가 사실은 "관심도"라는 하나의 축일 수 있습니다)

고유값 · 설명 분산(%)
각 성분이 전체 정보의 몇 %를 담고 있는지. 누적 분산이 70%를 넘는 지점까지의 성분을 쓰는 것이 일반적입니다.
적재량(Loadings)
각 원래 항목이 성분과 얼마나 밀접한지. 절댓값이 크면 그 성분을 대표하는 항목입니다.

수치형 열이 3개 이상일 때만 실행됩니다.

⑨ 신뢰도분석 (Cronbach's α) spss_reliability_summary / _items

여러 항목이 같은 것을 일관되게 재고 있는지 확인합니다. 설문 문항의 내적 일관성을 볼 때 쓰는 그 지표입니다.

α 값해석
0.9 이상매우 높음
0.7 ~ 0.9양호 — 일반적으로 이 이상이면 수용
0.7 미만낮음 — 항목들이 서로 다른 것을 재고 있을 수 있음

⑩ 교차분석 (카이제곱) spss_crosstab_<A>__<B> / spss_chisquare_summary

두 범주형 항목이 서로 관련 있는지 검정합니다. (예: 언론사에 따라 기사 유형 분포가 다른가?)

p-value가 0.05 미만이면 "두 항목은 독립이 아니다 = 관련이 있다"로 해석합니다. 범주형 열이 2개 이상일 때 실행되며, 유의한 조합에 대해서만 상세 교차표를 만듭니다(최대 8개).

⑪ 집단간 평균비교 spss_mean_comparison_summary / spss_groupmeans_… / spss_posthoc_tukey_…

범주에 따라 수치 평균이 유의하게 다른지 검정합니다. (예: 기사 유형별로 평균 좋아요 수가 다른가?)

  • 집단이 2개 → t-검정 (분산이 다르면 Welch 보정), 비모수일 땐 Mann-Whitney U
  • 집단이 3개 이상 → 일원배치 분산분석(ANOVA), 비모수일 땐 Kruskal-Wallis
  • ANOVA에서 유의한 차이가 나오면 Tukey 사후검정으로 어느 집단끼리 다른지까지 짚어 줍니다.

수치형·범주형 열이 모두 있을 때 실행됩니다.

조건을 못 채우면 그 분석만 조용히 빠집니다. 예를 들어 범주형 열이 없으면 교차분석·평균비교 표가 생성되지 않습니다. 어떤 분석이 왜 빠졌는지는 진행 로그에 이유와 함께 표시됩니다.

8. 공통 파생 표

분석 종류와 무관하게, 날짜 정보가 있으면 아래 표가 자동으로 더 생성됩니다.

요일 × 시간대 히트맵 hour_dow_heatmap

월~일 × 0~23시 격자에 게시량을 채워, 언제 활동이 가장 활발한지를 한눈에 보여줍니다. 평일 출퇴근 시간대 집중, 주말 야간 급증 같은 패턴을 찾는 데 씁니다.

이동평균 · 누적 <표이름>_trend / _cumulative

  • _trend — 7기간 이동평균. 일별 수치의 들쭉날쭉함을 눌러 추세를 봅니다.
  • _cumulative — 누적 합계. 전체적으로 얼마나 쌓였는지를 봅니다.

날짜 축이 있고 행이 8~400개인 표에만 붙습니다. 너무 짧으면 추세를 볼 수 없고, 너무 길면 그래프가 읽히지 않기 때문입니다.

9. 대용량 데이터 처리 방식

수백만 행을 넣어도 분석이 끝나도록, 결과가 거의 달라지지 않는 일부 단계에만 무작위 표본을 사용합니다. 어디에 표본을 썼는지는 결과에 분명히 적습니다.

단계처리 방식이유
군집분석 5만 행 표본
실루엣 계수는 1만 행으로 추정		 모든 데이터 쌍의 거리를 재는 계산이라 행이 2배면 시간은 4배가 됩니다. 집단 구조를 파악하는 데는 수만 행이면 충분합니다.
정규성 검정 5,000행 표본 검정 기법 자체의 표본 수 제한입니다.
산점도 그래프 5만 점 표본 점이 완전히 겹쳐 그림의 정보량이 늘지 않습니다. 제목에 표본 수를 표기합니다.

기술통계·빈도·상관·회귀는 전체 데이터를 그대로 씁니다. 평균·합계처럼 정확해야 하는 값은 표본을 쓰지 않습니다.

행이 아주 많을 때의 해석 주의: 수백만 행에서는 아주 작은 차이도 p-value가 0에 가깝게 나옵니다. "통계적으로 유의하다"가 "실질적으로 중요하다"는 뜻은 아니므로, p-value보다 효과의 크기(평균 차이·상관계수 값)를 함께 보세요.

10. 진행 로그 읽는 법

사이드바 작업 목록에서 작업을 누르면 지금 무엇을 하고 있는지 실시간으로 표시됩니다.

표시의미
[단계] …큰 흐름 — 데이터 읽기, 그래프 생성, 압축, 저장
[통계분석] (5/8) 회귀분석 …SPSS 분석 11종의 진행 상황 (몇 번째 / 전체)
[그래프] (7/20) …표에서 그래프를 만드는 중
[워드클라우드] …기간별 워드클라우드 생성 중
… 건너뜀 — 사유조건을 못 채워 생략된 분석과 그 이유

창을 닫아도 분석은 서버에서 계속됩니다. 다시 들어오면 사이드바 작업 목록에서 이어서 확인할 수 있고, 다른 기기에서 접속해도 같은 진행 상황이 보입니다. 작업이 끝나면 알림이 뜹니다.

12. 자주 겪는 문제 & 팁

12-1. 오류가 날 때

증상원인과 해결
필수 컬럼이 누락되었습니다 분석 종류와 CSV가 맞지 않습니다. 댓글 파일에 article 분석을 고르지 않았는지 확인하세요. 파일명의 _article/_reply/ _rereply가 분석 종류와 일치해야 합니다.
생성할 단어가 없습니다 워드클라우드에 원본 CSV를 넣은 경우입니다. 토큰화된 파일 (token_으로 시작)을 사용하세요.
지원되지 않는 옵션입니다 플랫폼 × 분석 종류 조합이 없는 경우입니다 — 3장 표를 확인하세요.
일부 표가 안 생김 조건 미충족입니다. 진행 로그의 건너뜀 메시지에 이유가 적혀 있습니다.

12-2. 더 좋은 결과를 얻으려면

  • 날짜 열 이름에 Date를 포함하세요. 그래야 요일×시간대 히트맵과 이동평균·누적 표가 만들어집니다.
  • 기간을 너무 넓게 잡지 마세요. 5년치를 일 단위로 보면 그래프에 선이 뭉개집니다. 월 단위 표(month_analysis)를 함께 보세요.
  • 감성·혐오도 수치는 자동 분류 결과입니다. 반어법이나 은어는 놓칠 수 있으니, 중요한 결론을 내리기 전에 top_controversial_replies 같은 원문 표에서 실제 댓글을 눈으로 확인하는 것을 권합니다.
  • 크롤링 DB에서 바로 선택하면 빠릅니다. 파일을 내려받아 다시 올릴 필요 없이 서버가 직접 읽습니다.
  • 오래 걸릴 것 같으면 예약을 쓰세요. 업무 시간이 끝난 뒤로 예약해 두면 다음 날 결과가 준비되어 있습니다.
