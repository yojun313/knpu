1. 시작 및 전체 흐름

POLYDECISION은 여러 기준의 상대적 중요도와 대안의 우선순위를 분석하는 연구 도구입니다. 연구자는 KNPU FPEI 계정으로 로그인하여 프로젝트를 관리하고, 응답자는 발급된 접속 링크·코드로 설문에 참여합니다.

  1. 새 프로젝트에서 연구 제목과 설명을 입력합니다.
  2. 계층 설계에서 목표, 기준, 하위 기준과 필요한 대안을 구성하고 저장합니다.
  3. 설문지에서 문항·안내문·동의 문구를 확인한 뒤 발행합니다.
  4. 수집에서 오프라인·온라인·실시간 수집을 운영합니다.
  5. 결과에서 가중치, 일관성, 대안 순위와 민감도를 확인하고 자료를 내보냅니다.
예시 연구: 정책 대안 A·B·C를 효과성, 비용, 실행 가능성으로 평가하는 경우입니다. 기준의 중요도를 먼저 구하고, 각 최하위 기준에서 대안을 비교하여 최종 우선순위를 도출합니다. 대안 계층을 사용하지 않으면 기준의 중요도만 분석합니다.

2. 계층·대안 설계

목표와 기준 구성

최상위 목표 아래 최상위 기준 추가로 기준을 등록합니다. 기준을 선택하면 기준 정보에서 이름·설명·하위 기준을 편집할 수 있습니다. 화살표로 순서를 조정하고, 브레인스토밍 항목을 트리에 반영한 뒤 저장을 실행합니다. 상단 계층도는 편집 내용을 시각적으로 확인하는 용도입니다.

같은 부모 아래의 항목은 동일한 관점에서 비교 가능한 수준으로 구성하는 것이 적절합니다. 의미가 중복되는 기준이나 기준과 대안이 혼재된 계층은 비교의 해석을 어렵게 합니다.

대안 평가

상세설정 → 대안 계층 → 사용을 선택하면 대안을 등록할 수 있습니다. 최하위 기준마다 대안 비교 문항이 생성됩니다. 기준 가중치만 필요한 연구는 대안 계층을 사용하지 않습니다.

계층을 변경한 뒤에는 설문지의 계층에서 새로고침으로 문항 구성을 확인합니다. 이미 응답을 수집한 설문의 구조·방법을 변경할 때는 기존 응답과의 비교 가능성을 먼저 검토해야 합니다. 화면에서 잠긴 설정은 배포된 설문 보호를 위한 제한입니다.

3. AHP·BWM 선택과 계산

계층 설계 → 분석방법에서 사용할 방법을 설정합니다. 현재 구현된 방법은 AHP와 BWM입니다. 발행된 설문의 분석방법은 변경할 수 없습니다.

구분AHPBWM
응답같은 부모 아래의 두 항목을 쌍대비교합니다.Best·Worst를 지정하고 Best 대비 각 항목, 각 항목 대비 Worst를 비교합니다.
가중치설정한 고유벡터법 또는 행 기하평균법으로 계산합니다.선형계획 모형으로 비음수 가중치의 합이 1이 되도록 계산합니다.
일관성CR과 임계값을 비교합니다.입력 일관성 CRI와 순서 일관성 OR을 확인합니다.
그룹 집계AIP 또는 AIJ를 선택합니다.개인 가중치를 기하평균 또는 산술평균으로 집계하고 정규화합니다.

AHP 응답과 집계

같은 중요도는 1이며, 한 항목이 더 중요할수록 해당 방향의 비교 강도를 높입니다. 반대 방향의 판단은 역수 관계입니다. 같은 부모 아래 항목이 n개이면 전체 쌍대비교는 n(n−1)/2개입니다.

  • AIP: 응답자별 가중치를 계산한 뒤 집계합니다. 화면의 기본 집계 방식입니다.
  • AIJ: 응답자들의 판단값을 먼저 집계하여 합성 비교행렬에서 가중치를 구합니다.

BWM 응답과 집계

Best와 Worst는 서로 다른 항목이어야 합니다. Best 자체와 Worst 자체에 대한 비교값은 1이며, 나머지 비교값은 1~9 범위입니다. 응답자마다 서로 다른 Best·Worst를 선택할 수 있습니다. 결과 화면의 지목 분포로 선택의 차이를 확인할 수 있습니다.

BWM의 기본 그룹 집계는 개인 가중치의 기하평균 후 재정규화입니다. 산술평균도 설정할 수 있습니다. AHP의 CR 임계값을 BWM의 CRI에 그대로 적용하여 판단하지 않습니다.

지역·전역 가중치와 대안 순위

지역 가중치는 동일 부모 아래에서의 상대적 중요도입니다. 전역 가중치는 목표에서 해당 기준까지 경로상의 지역 가중치를 곱하여 계산합니다. 대안 종합 점수는 최하위 기준의 전역 가중치와 해당 기준에서의 대안 지역 가중치를 곱한 뒤 합산합니다. 순위는 점수의 상대적 크기를 나타냅니다.

4. 분석 설정과 일관성

계층 설계 → 상세설정의 공통·AHP·BWM 탭에서 설정합니다.

  • 공통: 집계 방식, 대안 계층, 척도와 인구통계 수집 여부를 설정합니다.
  • AHP: 가중치 도출법, 불완전 응답 처리, CR 임계값과 초과 시 처리를 설정합니다.
  • BWM: CRI 임계값, 순서 일관성 검사와 그룹 집계 방식을 설정합니다. CRI 임계값이 0이면 항목 수·척도에 따른 자동 기준을 사용합니다.

AHP의 CR

CR은 비교 판단의 내부 일관성을 나타내는 지표입니다. 기본 임계값은 0.1입니다. 항목이 3개 미만인 그룹은 CR이 정의되지 않으므로 값이 없는 경우를 오류로 해석하지 않습니다. CR이 낮다는 사실만으로 판단의 객관적 타당성이나 표본의 대표성이 보장되지는 않습니다.

누락 응답

불완전 응답 처리는 제출 차단, 부분 응답 허용, 불완전 AHP(Harker법) 중 선택합니다. 부분 응답을 허용하더라도 모든 그룹에서 유효한 가중치를 계산할 수 있다는 뜻은 아닙니다. 연결이 부족한 비교나 미완료 그룹은 결과의 누락·제외 상태를 함께 확인해야 합니다.

일관성 경고와 제출 가능 여부는 별개입니다. CR 초과 시 경고 또는 차단 설정과 응답 화면의 안내를 확인합니다. 연구 보고에는 임계값, 누락 응답 처리, 제외 기준을 함께 명시하는 것이 적절합니다.

5. 설문지 편집·발행

  1. 계층을 저장한 뒤 설문지 단계로 이동합니다.
  2. 제목, 연구 목적·소요 시간 등의 도입 안내, 비밀유지·동의 문구를 입력하고 저장합니다.
  3. 자동 생성된 비교 문항과 항목 설명을 검토합니다. 계층 변경 사항은 계층에서 새로고침으로 반영합니다.
  4. 인구통계 수집을 사용하는 경우 항목과 선택지·코드를 설계하고 별도로 저장합니다.
  5. 인쇄 미리보기에서 응답자가 보는 구성과 문항 수를 확인한 뒤 발행을 실행합니다.

설문 발행 후에는 해당 설문을 대상으로 수집을 생성합니다. 수집이 시작된 뒤 변경이 제한되는 항목은 화면의 잠금 안내에 따라 처리합니다.

6. 응답 수집

수집 → 새 수집 시작에서 방식과 이름을 지정합니다. 하나의 프로젝트에서 여러 수집을 운영할 수 있으며 결과에서 합산하거나 범위를 선택할 수 있습니다.

방식운영 절차확인 사항
오프라인인쇄 설문을 배부하고 응답자별 자료를 입력 화면에 등록·제출합니다. CSV 가져오기도 활용할 수 있습니다.전사 오류, 비교 방향과 누락 문항을 원본과 대조합니다.
온라인접속 코드·링크를 발급하여 응답자에게 배포하고 응답 현황을 확인합니다.응답자별 코드가 혼용되지 않도록 관리합니다.
실시간참여자 접속 후 콘솔에서 세션을 시작하고 진행률·일관성을 확인합니다.라운드·섹션 진행과 결과 공개 시점을 관리합니다.

발급된 코드는 응답자 관리에서 다시 확인할 수 있습니다. 인구통계 수집을 활성화했다면 온라인·실시간 응답 과정 또는 종이 설문 하단에서 해당 항목을 수집합니다.

7. 실시간·델파이 운영

  1. 실시간 수집을 생성하고 참여자에게 코드·링크를 배포합니다.
  2. 콘솔에서 접속 상태와 참여자 목록을 확인하고 설문 시작을 실행합니다.
  3. 참여자별 진행률과 일관성을 확인합니다. 문항을 수정하여 저장하면 접속 중인 응답자 화면에 반영됩니다.
  4. 연구 절차에 따라 그룹 결과를 공개하고 다음 섹션 또는 다음 라운드로 진행합니다.
  5. 필요한 경우 섹션 재응답이나 개인 재조정을 요청한 뒤 결과 범위를 지정하여 비교합니다.
관리자가 응답값을 직접 변경하는 것은 응답자에게 재응답을 요청하는 것과 다릅니다. 직접 수정은 응답자와 확인한 값에 적용하는 것이 적절하며, 수정 이유와 델파이 운영 절차를 연구 기록으로 관리해야 합니다.

8. 결과 조회·해석

범위와 응답자

결과 범위의 기본값은 전체 합산이며 응답자별 최신 라운드를 사용합니다. 특정 수집·라운드를 선택한 경우 적용한 범위를 확인한 뒤 비교합니다. 인구통계 항목이 있으면 해당 필터를 적용하고 필터 초기화로 전체 범위로 복귀할 수 있습니다.

  • 전역 가중치: 목표를 기준으로 각 기준의 상대적 중요도를 확인합니다.
  • 대안 최종 순위: 기준별 기여와 합성 점수를 함께 검토합니다.
  • 기준별 합의도·극단값: 응답자 사이의 판단 차이를 검토하는 진단입니다. AHP의 쌍대비교 진단은 충분한 응답 자료가 있는 경우에 표시됩니다.
  • 일관성: 그룹 집계와 개인별 CR 또는 CRI를 구분하여 확인합니다.
  • 개인별 결과: 응답자를 선택하여 개인 가중치·대안 순위·일관성을 확인합니다.
  • BWM 지목 분포: 응답자들의 Best·Worst 선택 차이를 확인합니다.

민감도 분석

분석할 기준과 변화량을 지정하여 가중치 변화에 따라 대안 순위가 바뀌는지 확인합니다. 이는 현재 응답을 토대로 한 가정 변화의 결과이며 새로운 응답을 수집한 결과와는 구분해야 합니다. 작은 변화에도 순위가 바뀌면 점수 차이와 연구 조건을 함께 검토하는 것이 적절합니다.

9. 저장·내보내기

  • Word 설문지: 문항을 문서로 확인하거나 배포하는 용도입니다.
  • Excel 패키지: 분석 자료를 표 형태로 검토·정리하는 용도입니다.
  • CSV 원자료: 응답 자료를 별도 통계 도구에서 검토하는 용도입니다. 오프라인 가져오기는 시스템의 CSV 양식과 열 구조를 따라야 합니다.
  • 계층도 SVG·PNG: 설계 또는 결과 화면에서 저장합니다. SVG는 벡터 편집, PNG는 이미지 삽입에 활용할 수 있습니다.

설계·안내문·인구통계 항목의 저장 버튼은 각각 확인해야 합니다. 결과 범위나 필터를 적용한 경우 내보내기 화면과 파일의 대상 범위도 확인하여 연구 보고의 표본 수와 일치시키는 것이 적절합니다.

10. 문제 해결·연구 보고

결과가 비어 있습니다.

발행 여부, 수집 생성 여부, 응답 제출 여부를 순서대로 확인합니다. 선택한 수집·라운드와 인구통계 필터가 응답을 모두 제외했는지도 확인합니다. 미완료 그룹은 가중치 산출에 사용되지 않을 수 있습니다.

계층 변경 내용이 문항에 반영되지 않습니다.

계층 저장 후 설문지에서 계층 새로고침을 실행하고 문항을 검토합니다. 이미 배포된 수집의 잠금 안내가 있으면 기존 응답에 영향을 주는 변경인지 확인해야 합니다.

CR 경고가 높게 표시됩니다.

비교 방향을 반대로 입력했는지, 척도·항목 설명이 모호한지 확인합니다. 응답자의 실제 판단을 검토하고 필요하면 재응답을 요청합니다. 임계값 통과만을 목적으로 판단을 임의 변경하는 것은 적절하지 않습니다.

응답 링크로 접속되지 않습니다.

발급된 링크·코드를 다시 확인하고 해당 수집의 운영 상태를 확인합니다. 응답자용 링크와 연구자용 관리 화면 주소를 구분해야 합니다. 실시간 연결이 끊기면 재접속 후 저장된 진행 상태를 확인합니다.
