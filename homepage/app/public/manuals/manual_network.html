1. 분석 개요

단어 네트워크 분석(Word Network Analysis)은 토큰화된 텍스트 데이터(CSV)에서 단어들이 함께 등장하는 관계(공출현, co-occurrence)를 계산하여, 단어를 노드(node)로, 함께 등장한 관계를 연결선(edge)으로 표현하는 그래프를 생성합니다.

이를 통해 특정 주제 안에서 어떤 단어가 담론의 중심에 있는지, 어떤 단어들이 하나의 의미 덩어리(커뮤니티)를 이루는지, 단어들 사이의 관계 구조가 어떻게 형성되어 있는지를 정량적·시각적으로 파악할 수 있습니다.

본 기능은 상용 네트워크 분석 소프트웨어(NetMiner 등)에서 제공하는 핵심 분석을 자체 파이프라인으로 구현한 것으로, 대용량 데이터를 서버에서 병렬 처리하여 빠르게 연산합니다.

입력 데이터 조건: 이 분석은 토큰화된 CSV(예: token_...csv)를 대상으로 합니다. 각 셀에는 콤마(,)로 구분된 단어 토큰이 들어 있어야 하며, 기간 분할 분석을 사용하려면 Date를 포함하는 날짜 열이 있어야 합니다.

2. 작동 원리

2.1 공출현(Co-occurrence)의 개념

두 단어가 같은 문서(또는 같은 윈도우) 안에서 함께 등장하면, 두 단어 사이에 관계가 있다고 봅니다. 예를 들어 "학교폭력", "예방", "대책"이라는 단어가 여러 기사에서 반복적으로 함께 등장한다면, 이 세 단어는 강하게 연결된 관계로 그려집니다.

함께 등장한 횟수가 많을수록 연결선의 가중치(weight)가 커지고, 네트워크에서 더 굵고 진한 선으로 표현됩니다.

2.2 고속 공출현 행렬 계산

단어 쌍을 하나하나 세는 방식(이중 반복문)은 단어와 문서가 많아지면 매우 느립니다. 본 기능은 이를 희소 행렬(sparse matrix) 연산으로 대체합니다.

  • 문서 × 단어 형태의 이진 행렬 DT를 만든 뒤,
  • 행렬 곱 DTT × DT 한 번으로 모든 단어쌍의 공출현 횟수를 동시에 계산합니다.

이 연산은 내부적으로 멀티스레드(BLAS)로 처리되어, 수십만 건의 문서도 빠르게 집계됩니다. 또한 문서 집합을 CPU 코어 수만큼 나누어 병렬 처리합니다.

2.3 관계의 강도 보정 (연관성 척도)

단순히 "함께 등장한 횟수"만 쓰면, 원래 자주 나오는 흔한 단어끼리 무조건 강하게 연결되는 문제가 있습니다. 이를 보정하기 위해 Jaccard, Cosine, Dice, PMI 등 여러 연관성 척도를 선택할 수 있습니다. (자세한 내용은 6장 참고)

2.4 커뮤니티 탐지와 중심성

생성된 그래프에서 커뮤니티 탐지 알고리즘으로 서로 밀접하게 연결된 단어 그룹을 찾아내고(색으로 구분), 중심성 지표로 각 단어가 네트워크에서 얼마나 중요한 위치에 있는지 수치화합니다.

3. 분석 파이프라인

내부적으로 다음 순서로 처리됩니다.

  1. 단어 사전 구축: 최소 빈도·Top-N 조건에 맞는 단어만 선별
  2. 공출현 행렬 계산: 희소 행렬 곱으로 단어쌍 동시 출현 집계 (병렬)
  3. 연결선 생성: 선택한 연관성 척도로 가중치 계산 + 최소 임계값 필터링
  4. 백본 추출(선택): disparity filter로 핵심 연결만 남김
  5. 중심성 계산: degree, betweenness, pagerank 등
  6. 커뮤니티 탐지: Louvain / Leiden
  7. 전역 지표 계산: 밀도, 평균 경로 길이, 지름, 클러스터링 계수 등
  8. 레이아웃 계산: 노드 좌표 배치 (FR, KK 등)
  9. 결과 출력: PNG, HTML, CSV, GraphML, 요약 파일 생성

기간 분할을 선택한 경우, 각 기간마다 위 과정을 독립적인 프로세스로 동시에 수행하고, 마지막에 기간별 지표 변화를 비교하는 표와 그래프를 추가로 생성합니다.

4. 사용법

  1. 분석 탭에서 네트워크 분석 버튼을 클릭합니다.
  2. 파일 탐색기에서 분석할 토큰화된 CSV를 선택합니다.
  3. 설정 창(단어 네트워크 분석 다이얼로그)에서 원하는 옵션을 지정합니다.
  4. 결과를 저장할 위치를 지정한 뒤 OK를 누릅니다.
  5. 서버에서 분석이 진행되며, 진행 상황이 실시간 메시지로 표시됩니다.
  6. 완료되면 결과 폴더가 생성되고, 파일 탐색기에서 확인할 수 있습니다.

빠른 시작 권장 설정: 처음이라면 최소 단어 빈도 5, 최소 동시출현 횟수 2, 최대 노드 수 300, 연관성 척도 동시출현 빈도(raw), 커뮤니티 Louvain, 레이아웃 Fruchterman-Reingold로 시작해 보세요.

6. 연관성 척도 설명

두 단어 A, B에 대해, 함께 등장한 횟수를 c, 각각의 등장 횟수를 fA, fB라 할 때 각 척도는 다음과 같이 관계 강도를 계산합니다.

척도특징언제 쓰나
동시출현 빈도 (raw) 단순히 함께 등장한 횟수 c 그대로 사용. 가장 직관적. 절대 빈도가 중요할 때.
Jaccard c / (fA + fB - c). 두 단어가 등장한 전체 대비 함께 등장한 비율. 흔한 단어의 영향을 줄이고 싶을 때.
Cosine c / √(fA × fB). 벡터 코사인 유사도 개념. 빈도 차이가 큰 단어쌍을 공정하게 비교할 때.
Dice 2c / (fA + fB). Jaccard와 유사하나 공통 부분을 더 강조. Jaccard의 대안.
PMI 점별 상호정보량. 우연보다 얼마나 더 자주 함께 나오는지 측정. 흔한 단어를 눌러 의미 있는 조합을 부각할 때.
NPMI 정규화된 PMI. -1~1 범위로 스케일이 안정적. PMI를 쓰되 값의 범위를 일정하게 유지하고 싶을 때.

PMI / NPMI는 우연 대비 관계를 보는 척도라, 음(-)의 연관(서로 잘 안 나오는 쌍)은 연결선에서 제외됩니다.

7. 중심성 지표 설명

지표의미
Degree 직접 연결된 이웃 수. 많을수록 다양한 단어와 함께 쓰이는 단어입니다.
Strength 연결선 가중치의 합. 단순 연결 수가 아니라 관계의 강도까지 반영한 값입니다.
Betweenness 다른 단어들을 잇는 최단 경로 위에 얼마나 자주 놓이는지. 높으면 담론을 매개·연결하는 단어입니다.
Closeness 다른 모든 단어에 얼마나 가깝게 도달하는지. 높으면 네트워크 전반에 빠르게 영향을 미치는 단어입니다.
Eigenvector 중요한 단어와 연결될수록 높아지는 값. "영향력 있는 단어와 연결된 단어"를 찾습니다.
PageRank 구글 검색에 쓰인 알고리즘. eigenvector와 비슷하나 방향/가중치를 안정적으로 반영합니다.
Coreness (k-core) 노드가 속한 최대 k-core. 높을수록 촘촘하게 연결된 핵심부에 속한 단어입니다.
Constraint (구조적 공백) 낮을수록 서로 다른 그룹을 잇는 중개자 역할. 정보 흐름의 길목에 있는 단어입니다.

9. 인터랙티브 HTML 사용법

network.html을 웹 브라우저(크롬 권장)로 열면 다음 기능을 사용할 수 있습니다.

  • 드래그 / 휠: 화면 이동 및 확대·축소
  • 단어 검색: 상단 검색창에 단어를 입력하면 해당 노드로 이동·강조
  • 엣지 최소 가중치 슬라이더: 약한 연결을 숨겨 핵심 관계만 표시
  • 물리엔진 On/Off: 노드를 자동으로 정렬(엔진 On)하거나 고정(Off)
  • 전체 보기: 화면에 그래프 전체가 들어오도록 맞춤

노드·엣지가 매우 많을 경우, 브라우저 성능 보호를 위해 HTML에는 가중치 상위 일부 연결선만 표시됩니다. 전체 데이터가 필요하면 edges.csv 또는 network.graphml을 이용하세요.

10. 활용 팁 & 주의사항

  • 그래프가 너무 복잡하면 최소 빈도·최소 동시출현 횟수를 높이거나 Top-N을 줄여 단순화하세요.
  • 흔한 단어(예: "때", "말", "일")가 과도하게 중심에 오면 토큰화 단계에서 예외어로 제거하거나 PMI/NPMI 척도를 사용하세요.
  • 라벨이 노드에서 벗어나 보이면 라벨 겹침 방지를 끄고, 라벨 표시 개수를 20~25개로 줄이세요.
  • 커뮤니티가 잘 나뉘지 않으면 백본 추출을 켜서 핵심 연결만 남긴 뒤 다시 분석해 보세요.
  • 시간에 따른 담론 변화를 보려면 기간 분할을 사용해 period_comparison 결과를 확인하세요.
  • Top-N을 크게(수천 이상) 잡으면 betweenness 계산이 느려질 수 있습니다. 필요 없으면 중심성 선택에서 제외하세요.
