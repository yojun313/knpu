Get Started

1. DATABASE

1.1 개요

DATABASE 섹션은 MANAGER에서 DB와 관련된 모든 작업을 처리하는 핵심 모듈입니다. 데이터 조회, 검색, 병합 및 저장 등의 다양한 인터페이스를 제공합니다.

1.2 사용 방법

  • DB 삭제: 본인 소유의 데이터베이스를 선별적으로 삭제합니다.
  • DB 조회: 상위/하위 50개 데이터를 즉시 열람합니다.
  • DB 병합: 연속된 날짜의 데이터셋을 통합합니다.
  • CSV로 저장: 필터링 옵션을 적용하여 파일로 추출합니다.

1.2.1 검색 및 새로고침

검색 버튼 또는 검색창을 통해 특정 항목을 즉시 타겟팅할 수 있습니다. Ctrl + R 단축키를 통해 목록을 실시간으로 갱신합니다.

1.2.2 DB 병합 및 CSV 저장

병합 가능한 조건 충족 시 목록에 표시되며, CSV 저장 시 날짜 기간 설정 및 키워드 필터링(포함/제외) 옵션을 제공합니다.

2. CRAWLER

2.1 개요

지정된 웹사이트의 데이터를 자동 수집하고 데이터베이스로 직접 전송하는 서버 관리 섹션입니다.

2.2.1 크롤링 시작

크롤러 서버 1 크롤러 서버 2

서버 버튼 클릭 시 전용 대시보드로 이동하여 수집 현황을 실시간 모니터링할 수 있습니다.

3. ANALYSIS

3.1 개요

수집된 원천 데이터를 분석하고 시각화 지표를 산출하는 고급 분석 엔진입니다.

3.1.1 주요 기능

분할(년/월) 데이터를 기간별로 나누어 관리의 편의성을 높입니다.

통계 분석 지표에 따른 자동 분석 결과를 생성합니다.

KEM KIM 특화 분석 모델을 지원하며 자세한 내용은 매뉴얼을 참조하세요.

주의: 병합 시 선택한 모든 CSV 파일은 동일한 컬럼 형식을 유지해야 하며, "Open" 버튼을 눌러야 프로세스가 활성화됩니다.

4. BOARD

4.1 개요

릴리스 정보 확인, 버그 제보 및 커뮤니티 소통을 위한 보드 섹션입니다.

4.1.1 패치 노트 및 버그 리포트

추가 버튼을 통해 새로운 소식을 공유하거나 문제를 기록합니다. 특정 항목 클릭 시 팝업을 통해 상세 내용을 확인할 수 있습니다.

5. USER & SETTING

사용자 계정 관리 및 프로그램 전반의 환경 설정을 제어합니다.

  • User DB: 개인화된 데이터 저장소를 직접 제어하고 조회합니다.
  • Settings: 자동 새로고침, 알림 설정 및 테마 설정을 변경합니다.
